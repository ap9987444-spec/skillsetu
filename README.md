# SkillSetu

SkillSetu is a front-end prototype for an Academia × Industry platform focused on **student study paths, skill intelligence, internships and placement readiness**.

## Current build

The UI follows the supplied reference screens: dark left navigation, compact top bar, white analytics cards, blue/green/orange accents, progress indicators, tables and dashboard panels.

### Student journey
1. Choose a branch / career direction.
2. Follow a structured **year-wise study path**.
3. Open topic-wise notes, practice sets, quizzes and projects.
4. Build a verified skill profile.
5. See skill gaps against employer demand.
6. Discover matched internships and placements.
7. Track applications through a simple pipeline.

## Front-end structure

- `index.html` — dashboard and all prototype views
- `style.css` — responsive dashboard styling
- `script.js` — navigation, filters, theme and prototype interactions

## Planned backend integration

- Student/institute/company authentication
- Database for students, subjects, resources, skills and opportunities
- Role-based dashboards
- Real internship application workflow
- Skill assessment and recommendation engine
- Notifications and application status updates
- Admin/institution analytics
